Relatório Executivo — E-commerce Olist

Análise de dados transacionais de um marketplace brasileiro (2017–2018), transformando
dados de pedidos, logística, pagamentos e avaliações em uma narrativa executiva com
recomendações acionáveis para investidores e acionistas.

Projeto desenvolvido para o Tech Challenge — Fase 1, Pós-Graduação em Data Analytics.
